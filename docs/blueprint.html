Non-functional requirements

วันเปิดรับสมัคร

  • หน้างาน cache ที่ CDN, จำนวนคงเหลือดึงแยกผ่าน API สั้น ๆ
  • Waiting room เมื่อ RPS เกินเกณฑ์ ออก queue token
  • ตัดโควต้าด้วย UPDATE ... WHERE sold+reserved+n <= capacity ครั้งเดียว ไม่อ่านก่อนเขียน
  • เป้าหมาย: 3,000 checkout/นาที, p95 < 400 ms

เงินต้องไม่ผิด

  • เก็บเงินเป็นสตางค์ (BIGINT)
  • ทุก POST ที่เกี่ยวกับเงินต้องมี Idempotency-Key
  • Webhook ตรวจลายเซ็นและบันทึก event_id ไม่ให้ซ้ำ
  • Reconcile กับ gateway ทุกคืน แจ้งเตือนเมื่อยอดไม่ตรง

ความปลอดภัยและ PDPA

  • เข้ารหัสเลขบัตรประชาชน/พาสปอร์ต (AES-GCM) เก็บ hash แยกไว้ตรวจซ้ำ
  • ข้อมูลสุขภาพเห็นได้เฉพาะ role ที่จำเป็น
  • Consent แยกวัตถุประสงค์, ขอลบข้อมูลได้, audit log ทุกการเปิดดูข้อมูลส่วนตัว

งานเบื้องหลัง (Jobs)

  • ปล่อยโควต้าที่หมดเวลา ทุก 30 วินาที
  • ส่งอีเมล/LINE, ออกใบเสร็จ, สร้าง PDF ใบประกาศ
  • Export ไฟล์ใหญ่, คำนวณอันดับ, ปล่อยคิว waitlist
  • ทุก job ต้อง retry ได้โดยไม่เกิดผลซ้ำ

04

Flow ธุรกิจ

ลำดับขั้นของงานหลักทั้งหมด รวมกรณีขอบที่มักทำให้ระบบงานวิ่งพัง เช่น จ่ายเงินหลังหมดเวลา หรือคืนเงิน PromptPay

4.1 สมัครและชำระเงิน

จองโควต้า 15 นาทีตอนเริ่ม checkout ตัดโควต้าจริงเมื่อ webhook ยืนยัน

sequenceDiagram
  autonumber
  actor R as นักวิ่ง
  participant W as Web
  participant A as API
  participant D as PostgreSQL
  participant P as Payment Gateway
  participant Q as Job Queue
  R->>W: เลือกระยะและจำนวนคน
  W->>A: POST /checkout/sessions
  A->>D: UPDATE races SET reserved = reserved + n WHERE ยังเหลือพอ
  alt โควต้าพอ
    A-->>W: session_id + expires_at 15 นาที
  else เต็ม
    A-->>W: 409 SOLD_OUT พร้อมปุ่มเข้า waitlist
  end
  R->>W: กรอกผู้วิ่ง ไซซ์เสื้อ คำถาม add-on คูปอง
  W->>A: POST /orders พร้อม Idempotency-Key
  A->>D: order = PENDING_PAYMENT
  W->>A: POST /orders/:id/payments method=promptpay
  A->>P: สร้าง charge
  P-->>A: QR payload
  A-->>W: แสดง QR และเวลานับถอยหลัง
  R->>P: สแกนจ่ายในแอปธนาคาร
  P->>A: webhook charge.complete
  A->>D: บันทึก webhook_events ถ้า event_id ซ้ำให้ตอบ 200 แล้วจบ
  A->>D: TRANSACTION order PAID, reserved ย้ายเป็น sold, registrations CONFIRMED
  A->>Q: ส่งอีเมลและ LINE, ออกใบเสร็จ, กำหนดบิบ
  W->>A: GET /orders/:id ทุก 3 วินาที
  A-->>W: PAID แล้วพาไปหน้ายืนยัน

4.4 คืนเงิน

ผู้จัดเลือกได้ว่าจะอนุมัติอัตโนมัติตามนโยบาย หรือต้องกดอนุมัติเอง

sequenceDiagram
  actor R as นักวิ่ง
  participant A as API
  actor O as ผู้จัดงาน
  participant P as Payment Gateway
  R->>A: POST /me/registrations/:id/refund-request พร้อมเหตุผล
  A->>A: คำนวณยอดคืนจากนโยบายและวันที่ขอ
  alt อนุมัติอัตโนมัติ
    A->>P: refund ตามยอด
  else ต้องให้ผู้จัดอนุมัติ
    A->>O: แจ้งเตือนใน Backoffice
    O->>A: POST /org/:orgId/refunds/:id/approve
    A->>P: refund ตามยอด
  end
  alt บัตรเครดิต หรือ gateway รองรับคืน PromptPay
    P-->>A: webhook refund.succeeded
  else คืนผ่าน gateway ไม่ได้
    A->>R: ขอเลขบัญชีรับเงินคืน
    O->>A: แนบสลิปโอนคืน
  end
  A->>A: registration CANCELLED, คืนโควต้าและสต็อกเสื้อ, หักยอด payout ผู้จัด
  A-->>R: แจ้งผลทางอีเมลและ LINE
ช่วงเวลาที่ขอ (ตัวอย่างนโยบาย)คืนค่าสมัครโอนสิทธิ์เปลี่ยนระยะ
มากกว่า 60 วันก่อนงาน80%ฟรีฟรี + จ่ายส่วนต่าง
30–60 วันก่อนงาน50%ค่าธรรมเนียม ฿100฿100 + ส่วนต่าง

06

API

REST ที่ https://api.example.run/v1 ตารางนี้สรุปเฉพาะ endpoint หลัก ส่วนสเปกเต็มพร้อม schema อยู่ใน openapi.yaml

ข้อตกลงร่วม

  • Auth: Bearer JWT (นักวิ่ง/ผู้จัด/แอดมิน), staff token แยกต่องาน
  • Idempotency-Key บังคับบน POST ที่เกี่ยวกับเงิน
  • Error แบบ RFC 7807 application/problem+json พร้อม code เช่น SOLD_OUT, HOLD_EXPIRED
  • Pagination แบบ cursor: ?cursor=&limit=

Webhook และ rate limit

  • ตรวจลายเซ็นจาก header ของแต่ละ gateway
  • บันทึก webhook_events(gateway, event_id) unique และตอบ 200 เสมอเมื่อซ้ำ
  • Rate limit ต่อ IP และต่อ user, ตอบ 429 พร้อม Retry-After
  • Organizer endpoint ตรวจ role ใน org ทุกครั้ง

Backoffice และสิทธิ์

เมนูทั้งหมดของผู้จัดงานและแอดมิน พร้อมตารางสิทธิ์ของแต่ละ role ในองค์กรผู้จัด

เมนูผู้จัดงาน

  • Dashboard ยอดสมัคร รายได้ โควต้า เสื้อ
  • ข้อมูลงาน wizard, รูป, แผนที่, กติกา, นโยบายคืนเงิน/โอน, Draft → ส่งตรวจ → Publish
  • ระยะ & ราคา โควต้า, ช่วงราคา, รุ่นอายุ, ช่วงบิบ
  • ฟอร์มสมัคร form builder, ฟิลด์บังคับ
  • สินค้า เสื้อตามไซซ์, เหรียญ, ค่าส่ง, ประกัน, บริจาค
  • คูปอง % หรือบาท, จำกัดจำนวน/ระยะ, โควต้า VIP
  • ผู้สมัคร ค้นหา แก้ไข เพิ่มเอง ยกเลิก คืนเงิน
  • บิบ ออกอัตโนมัติ/เอง, ล็อกก่อนพิมพ์
  • Waitlist / โอนสิทธิ์ / เปลี่ยนระยะ คำขอรออนุมัติ
  • Export ผู้สมัคร, ประกัน, timing, โรงพิมพ์, ใบปะหน้า
  • ส่งข่าว อีเมล/LINE/SMS ตามกลุ่ม
  • หน้างาน จุดรับของ, บัญชี staff, real-time
  • ผลการแข่งขัน import, แก้, DQ, publish, template ใบประกาศ
  • การเงิน ธุรกรรม, payout, ใบกำกับภาษี
  • ทีมงาน เชิญสมาชิก กำหนด role

เมนูแอดมินแพลตฟอร์ม

  • ผู้จัดงาน KYC, อนุมัติ/ระงับ, ตั้งค่าธรรมเนียม
  • งานวิ่ง ตรวจก่อน publish, ตั้งเป็นงานแนะนำ
  • Orders & Support ค้น order/ผู้ใช้, impersonate แบบมี audit
  • คืนเงิน & Chargeback
  • Payout & Reconcile รอบโอน, ยอดไม่ตรง
  • ผู้ใช้ ระงับ, ลบข้อมูลตามคำขอ PDPA
  • CMS แบนเนอร์, บทความ, FAQ, policy
  • ตั้งค่า ช่องทางชำระเงิน, template อีเมล/LINE
  • รายงาน GMV, orders, conversion funnel
  • Audit log
